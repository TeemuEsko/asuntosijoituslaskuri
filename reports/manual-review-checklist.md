# Release Audit – manuaalinen tarkistuslista

- [ ] Visuaalinen selkeys kaikissa pääpoluissa
- [ ] Tekstit eivät tunnu käyttäjälle liian teknisiltä
- [ ] Varoitusten sävy ei ole liian voimakas
- [ ] Tarkistusnäkymä ei ole liian raskas
- [ ] Tärkeät tiedot löytyvät nopeasti
- [ ] Ammattilaisen arvio -osio näyttää luontevalta
- [ ] Mobiilinäkymä toimii
- [ ] Chrome, Edge, Firefox ja Safari toimivat odotetusti
- [ ] Oikeat anonymisoidut Etuovi- ja Oikotie-linkit toimivat
- [ ] Parserin lähdekatkelmat ovat ymmärrettäviä

Automaattisen auditin tulokset ovat tiedostoissa `release-audit.md` ja `release-audit.json`.
