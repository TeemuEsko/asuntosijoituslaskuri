# Document Pipeline

## Syöttötavat

1. ilmoituslinkki
2. dokumenttien lataaminen
3. manuaalinen syöttö

Kaikki tuottavat saman Property-mallin.

## Dokumenttityypit

- myyntiesite
- isännöitsijäntodistus
- PTS / kunnossapitotarveselvitys
- tilinpäätös
- yhtiöjärjestys
- energiatodistus
- osakeluettelo
- kuntotutkimus
- kosteuskartoitus
- muu dokumentti

## Osakeluettelo

Lisädokumentti.

Kun lisätään:

- avaa omistuspohjan keskittymisen tarkistuksen
- parseri ryhmittelee saman omistajan omistukset vain luotettavan tunnistuksen perusteella
- epävarma yhdistäminen jätetään tarkistettavaksi

## Live Analysis

Uuden dokumentin lisääminen:

1. parseroi dokumentin
2. yhdistää tiedot nykyiseen malliin
3. säilyttää käyttäjän arvot
4. suorittaa laskelmat ja säännöt uudelleen
5. päivittää analyysin kattavuuden
