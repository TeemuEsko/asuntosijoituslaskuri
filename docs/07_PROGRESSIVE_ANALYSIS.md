# Progressive Analysis

## Periaate

Analyysin syvyys riippuu saatavilla olevasta datasta.

Käyttäjää ei pysäytetä tarpeettomasti.

## Kattavuus ei ole sama kuin laatu

Kattavuus kertoo, kuinka moni tarkistus voidaan tehdä. Se ei ole sijoituskohteen pistemäärä.

## Tietojen luokat

### Päätöksen kannalta välttämätön

Ilman näitä keskeistä laskelmaa ei voida tehdä.

Esimerkiksi:

- velaton hinta
- markkinavuokra
- hoitovastike
- rahoituksen oletukset

### Analyysiä syventävä

Esimerkiksi:

- PTS
- tilinpäätös
- osakeluettelo
- kuntotutkimus

## Käyttöliittymä

Näytä:

- analyysin kattavuus
- mitä voidaan jo arvioida
- mitä ei ole vielä voitu tarkistaa
- mikä lisätieto avaa minkä tarkistuksen
