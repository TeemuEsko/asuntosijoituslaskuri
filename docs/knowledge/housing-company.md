# Taloyhtiö — tietopohjan runko

Tähän kootaan myöhemmin hyväksytty domain-tieto:

- vastikkeet
- talousarvio
- tilinpäätös
- korjausvelka
- PTS
- kunnossapitotarveselvitys
- tontti
- päätöksenteko
- omistuspohja

Tietopohja ei saa sekoittua suoraan sääntöihin. Sääntö viittaa hyväksyttyyn tietoon ja eksplisiittisiin raja-arvoihin.
