# RE-041 Yhtiölaina ja rahoitusvastike

Jos yhtiölainaosuus = 0:
- laskennallinen rahoitusvastike = 0
- positiivinen ilmoitettu rahoitusvastike aiheuttaa dataristiriidan
- ilmoitettu rahoitusvastike ja sen lähde säilytetään muuttamattomana evidenssinä
- ristiriitaa ei ratkaista automaattisella ylikirjoituksella

Poikkeus:
Rahoitusvastikkeen nimellä ilmoitettu muu pääomavastike on selvitettävä ennen johtopäätöstä.
