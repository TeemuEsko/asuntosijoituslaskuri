# RE-021 Omistuspohjan keskittyminen

Tarvitaan:
- osakeluettelo tai käyttäjän vahvistama tieto

Jos aineistoa ei ole, tila on `unchecked`.

Moottori laskee suurimman tunnistetun omistajan osuuden yhtiön osakkeista tai huoneistoista. Raja-arvot määritetään erikseen.

Viesti:
Omistuksen keskittyminen voi vaikuttaa päätöksentekoon, vastikeriskiin ja yhtiön hallintoon.
